# 🎓 Student Success Hub

**Plan your studies. Stay organized. Achieve your goals.**

Student Success Hub is a web-based study task management application designed to help students organize their academic tasks, track their progress, and manage their study schedules efficiently.

## 🌐 Live Demo

🚀 **Live Website:** https://student-success-hub-app.netlify.app

## ✨ Features

- 📝 Add study tasks with due dates.
- ✅ Mark tasks as completed.
- 🔄 Undo completed tasks.
- 🗑️ Delete tasks when they are no longer needed.
- 📊 View total, pending, and completed task counts.
- 💾 Save tasks in the browser using Local Storage.
- 📱 Responsive design for different screen sizes.
- 🎨 Clean and user-friendly interface.

## 🛠️ Technologies Used

- **HTML5:** Structures the web page.
- **CSS3:** Styles the website and provides a responsive layout.
- **JavaScript:** Handles task management and interactive functionality.
- **Browser Local Storage:** Saves tasks in the user's browser.

## 🚀 How to Run Locally

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your web browser.
4. Start adding and managing your study tasks.

## 🎯 Project Objective

The objective of Student Success Hub is to provide students with a simple and accessible platform to organize academic responsibilities, track task completion, and improve productivity and time management.
